Methodology

What It Measures

Rates how walkable a location is on a 0-100 scale based on proximity to 13 amenity categories. Higher = more walkable.

Categories (weighted)

  • Grocery & Transit (3x weight)
  • Restaurant, Park, School, Healthcare (2x)
  • Shopping, Cafe, Pharmacy (1.5x)
  • Bank, Entertainment, Fitness, Bookstore (1x)

Adjustments

  • Highway barrier detection (2.5x distance penalty)
  • Diversity bonus for multiple nearby options
  • Slope penalty for hilly terrain
